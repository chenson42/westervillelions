## 1.61.0 — 2026-08-08

### Defect Fix: Budget-committee members still could not reach the Ledger

**Problem:** A member given a budget-committee role — created so a non-officer could review the draft
budget — was still bounced away from the budgeting page. This was reported once before and addressed in
v1.55.0; that release fixed part of it and the member remained locked out.

**Root Cause:** Access to admin pages is decided in more than one place. v1.55.0 corrected the admin
page layout and the navigation link, but requests are checked earlier still, and that earlier check had
no rule for the Ledger — so anything under it fell through to a catch-all requiring the full
administrator permission. The earlier fix could never take effect, because the request never reached it.

**Fix:** The Ledger now admits anyone holding any ledger or budget permission, checked at that earlier
layer. Each page inside still applies its own finer requirement — someone who can view budgets but not
manage categories is admitted to the Ledger and then declined at that page, gracefully.

**Testing:**
- [x] Verified by signing in as an account with exactly the affected member's permissions and opening
      the budgeting page — rather than by reading the code, which is how this survived a previous fix.
- [x] The fix was then reverted to confirm the failure reproduced, and restored — proving the new
      regression test catches it.
- [x] A permanent test now guards this path.

### Feature: Donor thank-you and acknowledgment letters

**Value:** The club sends written acknowledgments for gifts of $250 and over — the letter that lets a
donor claim their deduction, and equally the thank-you a local business deserves for sponsoring the
Rudolph Run. Until now that happened entirely outside the system, which is why 49 past gifts had no
record of a letter at all. This brings it in.

#### What's New

- **Letters are generated for you**, combining the club's own thank-you wording with the wording the IRS
  requires — the club's name and tax ID, the amount, and the statement about whether anything was
  received in return.
- **The club's wording is yours to edit** — greeting, body, closing, and signature — from Settings, with
  a live preview. The required legal paragraph is generated and cannot be edited away, so a reworded
  letter can never become an invalid one. The preview shows which parts are yours and which are fixed.
- **Generate one letter or a whole batch.** Select a set of gifts — every Rudolph Run sponsor, say — and
  produce them together, one letter per page, ready to print or save as a PDF.
- **Letters adapt to the gift.** A straightforward donation states that nothing was provided in return.
  A gift where the donor received something — a race entry, for instance — states what they received,
  its value, and the deductible portion.
- **A letter, once sent, is fixed.** Editing the club's wording later never changes a letter already
  produced, and a letter already marked sent cannot be regenerated.
- Gifts in categories that never need an acknowledgment — event registrations, grants, internal
  transfers — are excluded automatically.

#### Permissions

| Feature key | Required for |
|-------------|--------------|
| `ledger.record` | Generating and printing letters |
| `ledger.manage` | Editing the club's letter wording |

No new permission key.

#### New Routes

- `GET /admin/ledger/donors/letters` — select gifts, generate, and print
- `GET /admin/ledger/settings/acknowledgment-letter` — edit the club's wording

### Enhancement: Donors can have more than one email address

**Value:** The club's first recorded donor asked for correspondence to go to two people. A donor record
held one address.

**Changes:**
- A donor can now hold any number of email addresses, added and removed individually, and shown on the
  donor record.
- Searching for a donor matches on any of their addresses.
- Letters are printed rather than emailed in this release, so the addresses are recorded now and will be
  used when emailing arrives.
