## 1.14.0 — 2026-05-18

### Refactor: Wall-Clock Event Times + Feature: All-Day Events

**Value:** Event times entered in the admin form were stored as `timestamp without time zone` in PostgreSQL but read by Drizzle as UTC `Date` objects, causing a systematic 4–5 hour display shift for users in Eastern Time (e.g., "12:30 PM" displayed as "8:30 AM"). This release eliminates the bug at the source by treating all event timestamp columns as raw wall-clock strings end-to-end, and adds first-class support for all-day events that display without a time component.

#### What Changed

**Wall-clock model (systemic refactor)**

- Drizzle `mode: "string"` applied to `startDate`, `endDate`, `recurrenceEndDate` on `events` and `occurrenceDate` on `eventRsvps`. Drizzle now returns raw Postgres `"YYYY-MM-DD HH:MM:SS"` strings instead of `Date` objects — eliminating the UTC round-trip.
- New `parseWallClock(s: string | Date): Date` helper in `src/lib/events.ts` — parses wall-clock strings using date-fns `parse()` in local timezone (Eastern).
- New `dateKey(d: Date): string` helper — derives `"YYYY-MM-DD"` from local (not UTC) date components. All four occurrence-date key derivation sites in the codebase updated atomically.
- New `easternOffsetFor(d: Date): "-04:00" | "-05:00"` helper — DST-aware Eastern offset used in event JSON-LD structured data.
- All Drizzle WHERE clauses that compared event date columns to `Date` objects migrated to string comparisons (`format(now, "yyyy-MM-dd HH:mm:ss")`).

**All-day events**

- New `isAllDay` boolean column on `events` table (default `false`).
- New `formatEventWhen(event): string` helper in `src/lib/events.ts` — centralizes display logic: returns `"All Day · MMMM d, yyyy"` for all-day events, and the timed format for all others.
- Admin event form gains an "All-day event" checkbox; when checked, the time pickers are hidden.
- Public event detail page (`/events/[id]`) uses date-only ISO format in JSON-LD structured data for all-day events.
- All event display surfaces use `formatEventWhen` for consistent rendering.

#### Permissions

No new permission keys. No role binding changes required.

#### Schema Changes

- **Modified:** `events.start_date`, `events.end_date`, `events.recurrence_end_date` — Drizzle `mode: "string"` annotation (TypeScript only, no DDL change).
- **Modified:** `event_rsvps.occurrence_date` — Drizzle `mode: "string"` annotation (TypeScript only, no DDL change).
- **New column:** `events.is_all_day` (`boolean NOT NULL DEFAULT false`).
- **Migration:** `drizzle/migrations/0037_events_wall_clock_and_all_day.sql` — single idempotent `ALTER TABLE events ADD COLUMN IF NOT EXISTS is_all_day boolean NOT NULL DEFAULT false`.
