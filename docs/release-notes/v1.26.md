## 1.26.0 — 2026-07-20

### Enhancement: Fund-Compliance Guardrails (The Ledger, increment 7)

**Value:** The Ledger already enforces LCI's core two-fund rule (Administrative vs. Activities funds plus the Activity→Admin transfer firewall). Research against Lions Clubs International's published financial governance — the Standard Club Constitution Art. VII §3(g) and LCI treasurer guidance — surfaced three completeness gaps. This release closes all three, so a treasurer sees a warning *before* an auditor or district review would.

**Changes:**

- **Aged public-fund warning.** LCI guidance says public (Activity/Charitable/Scholarship) funds "must be returned to public use" within a reasonable time — usually one year — unless earmarked for a specific project. The Ledger overview now raises a WARN when a public fund holds a positive balance whose oldest posted income is older than the configured holding period. The check uses the fund's true life-to-date balance and income age, so it fires regardless of which fiscal-year view is selected. The warning text reminds the treasurer that legitimate multi-year projects should be earmarked in board minutes.
- **New setting: "Public fund holding period (days)."** The aging threshold is configurable on the Ledger settings page (default 365 days, positive whole numbers only), alongside the existing reserve-threshold guardrail setting.
- **Direct-to-admin public income warning.** The firewall catches Activity→Admin *transfers*, but a public/fundraising-categorized donation recorded *directly as income into the Administrative fund* used to slip through. That now raises a WARN as well.
- **Authoritative citation.** The two-fund firewall flag (and the new direct-to-admin flag) now cite **Standard Club Constitution Art. VII §3(g)** in addition to the internal Lions Financial Transparency Policy §6, so a treasurer can point an auditor at the constitutional text directly.

No new permission keys — the guardrails surface on the existing Ledger overview (`ledger.view`); the new setting is edited under the existing `ledger.manage` gate.

**Deferred by design:** an earmark mechanism (marking a fund's balance as committed to a multi-year project so the aging WARN skips it) is a tracked follow-up. The v1 warning is intentionally non-urgent (WARN severity) so it informs without nagging.
