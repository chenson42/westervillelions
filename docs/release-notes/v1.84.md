## 1.84.0 — 2026-09-29

### Feature: Change a setting on every upcoming meeting at once

**Value:** The club's General, Activities and Board Meetings for 2026-27 live on the calendar as
separate events, one per date, rather than as a repeating series. That is deliberate — the real
schedule has exceptions a repeating rule can't express (the board's night changed mid-year,
November's board meeting moved off Thanksgiving, December has no board meeting at all) — but it
meant that turning RSVP off on "the Board Meeting" only turned it off for the one date that was
open. Every other month kept asking members to RSVP, and the only way to finish the job was to
open each date by hand. Twenty-one meetings had to be corrected outside the app this week.

#### What's New

- When an administrator edits an event that shares its exact title with other upcoming events,
  the edit form now shows how many there are and offers a checkbox: *Also apply to N other
  upcoming "Board Meeting" events*. It is off by default and only appears when there is something
  to apply to.
- Ticking it and saving opens a confirmation that lists exactly which fields changed and every
  date that will be updated, so an accidental match between two unrelated events with the same
  name is visible before anything happens. Past events are never touched.
- Only settings that make sense to share are carried across: location, description, public
  visibility, RSVP on/off, maximum attendees, guest count, and the sign-up question. Each
  meeting keeps its own date and time. Existing RSVPs on the other meetings are kept when RSVP is
  switched off.
- If the title itself is being changed in the same save, the other meetings are matched on the
  name they had *before* the edit, and the confirmation says so.
- After saving, the message reports how many other events were actually updated, not how many
  were expected.
- Saving without the box ticked behaves exactly as it did before.

Changing the time or duration of a whole schedule at once is not part of this release and is
tracked as a follow-up.

#### Permissions

| Feature key | Required for |
|-------------|--------------|
| `events.edit` | Editing an event, with or without applying the change to its siblings |

No new permission was added; the same check that guards a single-event edit guards the fan-out,
and it is re-checked on the server.

#### Also in this release

- The October 23 Fourth Friday booth in Uptown Westerville, announced in the September issue of
  The Tracks, has been added to the member calendar so members can sign up to staff it.
- RSVP has been turned off on all remaining upcoming General, Activities and Board Meetings
  through June 2027, completing the change that prompted this feature. The December 17 Christmas
  Party still takes RSVPs.
