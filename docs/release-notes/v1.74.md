## 1.74.0 — 2026-09-04

### Feature: Type-to-find search in the admin menu

**Value:** The admin area has grown past twenty sections; finding the right one meant scanning
the whole sidebar. Now it works like the search in your phone's Settings app.

#### What's New

- A search box at the top of the admin sidebar filters the menu live as you type
- Matching is forgiving — it finds partial and scattered letters ("emq" finds Email Queue),
  and it knows synonyms: typing "money" surfaces the Ledger areas, "facebook" surfaces Social
  Requests, "990" surfaces Compliance
- Matched letters are highlighted; sections with no matches disappear until you clear the
  search (Escape or the ✕ clears it)
- Search only ever narrows what your permissions already let you see

### Enhancement: Event links now always unfurl with an image when shared

**Value:** Pasting an event link into a text message, Facebook, or a group chat should expand
into a rich preview — picture, title, description — the way news links do.

**Changes:**
- Every event link now unfurls with an image: the event's own picture when it has one, the
  club's brand photo when it doesn't (previously, events without a picture unfurled as bare
  text — which was all of them)
- X/Twitter previews now show the event's image instead of the generic site image
- The admin event form's image field now explains the wide-banner crop, the recommended
  minimum size, and that the image doubles as the shared-link preview
