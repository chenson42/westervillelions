## 1.53.0 — 2026-07-30

### Feature: Budgeting is now an overview → drill-down surface

**Value:** The budgeting page stacked every fund's full editor on one long, cramped page — hard to
navigate and hard to present. It's now structured like the Ledger: an at-a-glance **overview** of all
funds, with a full-width editor when you **drill into** a single fund.

#### What's New
- **Overview page** (`/admin/ledger/budgeting`) — a per-fund summary row showing **Beginning Bank
  (Jul 1) · Income · Expenses · Net · Final Bank (Jun 30)** plus an all-funds total, the Draft/Approved
  status, Approve-&-Lock / Unlock, the **Print** button, and a new budget-level **Notes & Assumptions**
  field. Each row links into its fund with an "Edit budget →" affordance.
- **Drill-down page** (`/admin/ledger/budgeting/[fund]`) — the full editor for one fund at a time:
  categories, cause/line-item breakdown, add/remove at every grain, star/notes, prior-year reference
  columns, live totals — full width so it can breathe.
- **Board-ready printable budget** — a consolidated all-funds summary front page + per-fund detail,
  with beginning/projected-ending balances (shown as reference, not folded into the budget math),
  income/expense subtotals + a Net Surplus/(Deficit) line, a Draft-vs-Approved stamp, the budget
  notes, a reconciliation footnote, and page-break pagination. Follows nonprofit board-presentation
  conventions.
- **Budget-level Notes & Assumptions** — free-text commentary about the whole budget (distinct from
  per-line star/notes), which prints on the board document. Works on a *draft* budget and stays
  editable even after the budget is locked (commentary isn't a figure).

#### Under the Hood
- One shared `computeFundPlanSums()` feeds the overview screen **and** the printed report, so on-screen
  and printed totals can never diverge.

#### Permissions
Unchanged — `budget.view` / `budget.edit` / `ledger.manage` / `ledger.approve` gate both routes; lock
and approval remain overview-only by placement.

#### Schema
New `ledger_budget_notes` table (migration `0071`).
