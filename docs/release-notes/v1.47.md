## 1.47.0 — 2026-07-28

### Feature: "Environment" Budget Cause

**Value:** Environmental giving (tree plantings, conservation, city green-space events
like Arbor Fest) had no home in the budget cause list — treasurers had to misfile it
under a recycling or catch-all bucket. It now has its own cause, so it groups correctly
on the budgeting worksheet and in the /members/impact "giving by cause" breakdown.

#### What's New

- **Environment** is now selectable wherever a budget cause is chosen (the "Break down
  by cause" line editor), alongside the existing eight causes. No new permission — it's
  available to anyone who can already edit budgets (`ledger.manage`).

### Defect Fix: Budgeting Totals Stopped Updating After Edits

**Problem:** On the budgeting page, the live **Income / Expenses / Banked-used** totals
under each fund only reflected the numbers present when the page first loaded. After
adding a category, restoring a removed line, or committing a cause breakdown, the totals
went stale until a full manual page reload.

**Root Cause:** The totals were summed from state seeded once when the page mounted.
Every edit refreshes the page's server data, but that seed never re-ran, so the totals
stayed frozen at their initial values.

**Fix:** The totals now re-sync from the server data on every refresh and page load, in
addition to updating live per keystroke — so they always match what's actually saved.
