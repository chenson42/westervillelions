## 1.95.0 — 2026-10-12

### Feature: Santa's Workshop worker app and photo storage

**Value:** Volunteers can now run Santa's Workshop from their phones. They open a private page, type the shared event code (no club login needed), and work down the list of registered stuffies: tag one by scanning its sticker, check it in with a first photo while the snack choice and care note are on screen, take its one portrait with Santa and Mrs. Claus (and retake it if it isn't right), snap group photos, and hand the stuffy back after seeing the name on the order and confirming who is collecting.

#### What's New

- If the signal drops or photo storage has a problem, photos wait safely on the phone and send themselves later, and nothing stops the line.
- Admins can open and close a session, share or change the event code, pause volunteer access, add a family by hand with a reason, handle refunds, test photo storage, and run a practice session first. A wrong step on a practice session can be reverted; on the real event an admin can revert with a recorded reason.
- The check-in photo is shown again at the portrait and pickup steps, so the volunteer can confirm it is the right stuffy.
- Volunteers never see families' email addresses or phone numbers. The parent's name appears only when a volunteer asks for it at pickup, and the record shows that it was shown and who confirmed.
- Photos are stored in a private shared drive in the club's Google Workspace, never on the website's database.

#### Permissions

- None new. The worker page is opened with the session's event code; admins and board members manage sessions as before.

#### New Routes

- `GET /santas-workshop/crew/<session>` — the worker app (event code required)
- `GET /api/santas-workshop/photos/<id>` — serves a photo to a signed-in worker or admin; every failure is a 404
