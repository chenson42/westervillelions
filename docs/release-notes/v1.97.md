## 1.97.0 — 2026-10-13

### Feature: Santa's Workshop printed frames

**Value:** Admins can now make a printed keepsake frame for every stuffy. From a laptop, the Frames page prepares the list (who gets a frame, who is left out and why), then makes a 4x6 picture for each stuffy with its portrait, its name, a small frame number and a code that opens the day's photos, in numbered zip files of about 100 pictures ready to upload to a photo counter.

#### What's New

- The zip files contain pictures only. The list of who is who is a separate download for the admin, so nothing about a family goes to the photo counter.
- If a portrait is retaken afterwards, only that frame needs to be made again, and it gets a fresh file name so the counter never confuses it with the first print.
- The page never presents a set as complete when a frame is missing, lists what failed, and can retry just those.
- A real event's frames can only be made from the club's live website, so the code on every printed frame always opens the right page. Practice sessions are exempt so the dry run can rehearse the whole thing.
- Until the chair supplies frame artwork, a clean default frame in the club's colours is drawn automatically; a 1200 by 1800 overlay with a clear window drops in when it arrives.

#### Permissions

- None new. The Frames page uses the existing Santa's Workshop permission.

#### New Routes

- `GET /admin/santas-workshop/<session>/frames` — prepare and export frames (admin, laptop)
