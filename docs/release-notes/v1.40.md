## 1.40.0 — 2026-07-27

This release lets you plan a giving budget at the level of *cause* — the same
grain the member Impact dashboard already reports giving in — while leaving the
simple "one number per category" workflow exactly as it was for everything else.

### Feature: Cause-Level Budget Detail

**Value:** Until now a budget category was a single dollar figure. But a category
like "Charitable donations out" really funds several distinct causes — Youth &
Education, Hunger Relief, Disaster Relief, and so on — and the board often wants
to plan (and later report) at that finer grain, matching how the Impact
dashboard already shows giving *by cause*. This is the planning half of that:
you can now build a category's target up from cause line items.

#### What's New

- **Break a category down by cause.** On the Budgeting page (and each fund's
  report), a giving-eligible expense category now offers a **"Break down by
  cause"** option. Switching to breakdown mode starts you off with your existing
  amount carried forward as a single **"Other community support"** line — the
  same label the Impact dashboard uses — which you can then split across causes.
- **Cause line items.** Add a line, pick a cause from a **fixed list** (the same
  eight causes the club's historical giving is already categorized into), and
  enter an amount. The category's target becomes the **sum of its cause lines**,
  updated live as you edit. Each cause can appear once per category, so a
  category's breakdown always adds up cleanly.
- **Lump sum still works, untouched.** Categories you don't break down — and all
  revenue and administrative categories — behave exactly as before: one amount,
  one line. Breakdown is only offered where a cause is actually meaningful
  (giving expense categories).
- **Collapse back to a lump sum** at any time; the total dollar figure is kept,
  though the per-cause detail is cleared (you're asked to confirm first).
- **Seed cause detail from history.** The guided "start from last year" flow can
  now also propose cause lines, built from the past two fiscal years of
  cause-tagged giving (using the most recent year's amount where they differ). If
  a category has no cause history yet, it simply stays a lump sum with a "no
  cause history yet" note rather than a confusing empty panel.
- **Respects the year lock.** Cause lines are covered by the same approve/lock
  introduced in v1.39 — once a fiscal year's budget is locked, its cause lines
  can't be added, edited, or removed until it's unlocked.

#### Also Fixed

- **A budget total could silently disagree with its own cause lines.** The older
  "single amount" save path was unaware of cause lines, so breaking a category
  down by cause and *then* editing its lump sum (or re-running "start from last
  year" in overwrite mode) could leave the category's headline total out of sync
  with the causes beneath it — with no warning. That path is now guarded: it
  refuses to overwrite a category that's been broken down by cause (pointing you
  to edit the cause lines instead), and the seeding flow **skips** any
  broken-down category and tells you how many it skipped.

#### Permissions

| Feature key | Required for |
|-------------|--------------|
| `ledger.manage` | Building/editing cause lines (same permission as editing any budget) |
| `ledger.approve` | Locking/unlocking a year's budget, cause lines included |

_No new permission key — cause detail reuses the existing budgeting gates._

#### New Routes

- `PATCH /api/admin/ledger/budgets/cause-lines` — Add or update one cause line on a category (also enters breakdown mode)
- `DELETE /api/admin/ledger/budgets/cause-lines` — Remove one cause line (removes the category's target entirely if it was the last line)
- `POST /api/admin/ledger/budgets/cause-lines/collapse` — Collapse a breakdown back to a single lump-sum amount
- `POST /api/admin/ledger/budgets/seed` — Extended to optionally seed cause-level lines from prior-year giving
