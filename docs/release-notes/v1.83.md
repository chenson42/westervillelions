## 1.83.0 — 2026-09-28

### Enhancement: Public forms now reject automated junk submissions

**Value:** Since September 23, an automated program had been repeatedly filling out the contact
form, the newsletter signup, and the membership application. The name and message fields were
random strings of letters, but the email address on each submission belonged to a real person who
had never contacted the club — the program was using harvested addresses, not its own. Because the
forms couldn't tell the difference, the club was sending its "we received your message"
confirmation to strangers, and quietly adding their addresses to the newsletter list. Every run
also left junk in the inbox at info@westervillelions.org for someone to sort through by hand.

**Changes:**
- Submissions that look like automated filler are now discarded silently — no confirmation email
  goes out, no address is added to the newsletter, and nothing is sent to info@. A real visitor
  sees the exact same "Message Sent," "You're subscribed," or "Application Received" confirmation
  they always have; nothing about filling out the form changes for them.
- The same email address can no longer submit more than one of the three public forms within two
  minutes — the pattern the automated submissions followed.
- The spam check that already runs on these forms (Cloudflare Turnstile) is now stricter, closing a
  gap that had let the automated submissions through undetected.
- Membership applications are still reviewed by hand before anyone is contacted, so an occasional
  piece of junk may still appear there for the reviewer to dismiss — it will no longer reach anyone
  outside the club, and it won't touch the newsletter list or send a confirmation to a stranger.

A club administrator can run a one-time cleanup separately to remove the junk already recorded
from the affected forms; that isn't part of this release and doesn't affect anything described
above.
