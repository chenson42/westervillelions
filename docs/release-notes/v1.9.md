## 1.9.0 — 2026-05-01

### Feature: Create User from Admin; Scroll-to-Attendance

**Value:** Admins can now create user accounts directly without requiring the member to self-register. Clicking "View all RSVPs →" on an event now scrolls directly to the attendance section on the edit page.

**Changes:**
- Admin → Users page has a new "+ Add User" button that opens a modal dialog
- Admins can set name, email, temporary password, and optionally link the new account to a member record on creation
- The "member" role is automatically assigned to all newly created accounts
- If a member is linked and no name is provided, the name is pulled from the member record automatically
- "View all RSVPs →" link on the admin events list now navigates directly to the `#attendance` anchor on the event edit page
