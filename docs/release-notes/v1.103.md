## 1.103.0 — 2026-11-09

### Feature: announcements are banner buttons

**Value:** Whatever the club is promoting right now (Santa's Workshop sign-ups today, White Cane in October) gets the big gold button at the top of the homepage, switched on and off from the Announcements page with no code change.

#### What's New

- **Any announcement can take the hero button.** The first active announcement (by sort order) appears as the gold button in the homepage banner, and a second one, if there is one, as an outlined button. "Join the Club" moves to the outlined slot beside them. With no active announcement the banner shows Join the Club and Attend a Meeting as before.
- **The button text** is the announcement's link label, or its title when the label is blank.
- **Start and end dates control it.** Set the end date to when sign-ups or the campaign close, and the button disappears on its own.
- **Announcements no longer appear as a list** in the What's Happening section, which now shows upcoming events only.
- **A link is now required** on an announcement, since the button is the only place it shows. The body field is kept as internal notes and is not shown on the website.
