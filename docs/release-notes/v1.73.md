## 1.73.0 — 2026-09-04

### Feature: Club Files

**Value:** The club had no way to put a document on the website — the immediate need was the
2026 Rudolph 5K & Winterfest sponsorship packet, which should be downloadable by any
prospective sponsor straight from the event's page. Documents like this can't simply be
dropped into the website's source code (they often contain contact details, and the code is
public), so the club needed a proper home for them: uploaded through the admin area, stored
securely, and served with the right visibility.

#### What's New

- **Upload club documents** — admins upload PDFs (up to 25MB) at the new Club Files admin
  area, with a progress bar for larger files
- **Public or members-only** — every file carries a visibility setting, enforced on every
  single download: public files download for anyone, members-only files require a signed-in
  club member, and outsiders probing for private files get a plain "not found" — no hint the
  file exists
- **Attach files to events** — a file attached to an event appears as a download link on that
  event's page. The sponsorship packet on the Rudolph Run page is the first: "Become a
  sponsor" is now one click for any visitor
- **Files in Club Records** — members find every club file, public and members-only alike, in
  a new Files section of the Club Records hub
- **Next year is 30 seconds** — replacing a file (like next season's packet) swaps the
  document in place: same link, same event attachments, new content, no developer involved

#### Permissions

| Feature key | Required for |
|-------------|--------------|
| `club_files.manage` | Uploading, editing, attaching, and deleting files (Admin role only) |

Viewing and downloading needs no special permission — public files are open to everyone, and
members-only files are open to any signed-in club member.

#### New Routes

- `/admin/club-files` — upload and manage files, set visibility, attach to events
- `/members/records/files` — the Files section of Club Records
- Download links appear on event pages for attached files
