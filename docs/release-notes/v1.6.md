## 1.6.10 — 2026-04-12

### Feature: Persistent Email Queue with Retry

**Value:** Previously, any Resend API failure silently dropped the email with no way to recover. All emails are now persisted to a queue table before sending, with automatic retries and an admin UI to manually retry failures.

**How it works:**
- Every email is inserted into `email_queue` before sending
- Up to 3 send attempts per request (500ms between retries)
- On failure: status set to `failed`, `next_retry_at` set to 15 minutes from now
- Admin can view and retry failed emails at `/admin/email-queue`

**Emails covered:** contact form (2 emails), password reset, membership welcome, unlinked user alert

## 1.6.5 — 2026-04-11

### Defect Fix: Badge and Link Misaligned with Centered Single Event Card

**Problem:** "Upcoming Events" badge and "See All Events" link stayed left-aligned while the single event card was centered.
**Root Cause:** The `max-w-2xl mx-auto` constraint only wrapped the card, not the badge or link above/below it.
**Fix:** Moved the constraint to wrap all three elements together.

## 1.6.3 — 2026-04-11

### Feature: Members Event Detail Pages; Fix Missing Private Events

**Value:** Members can now drill into any event (public or private) for full details, and newly added private events appear immediately without waiting for cache expiry.

## 1.6.2 — 2026-04-11

### Defect Fix: Event Cards Too Wide on Members Events Page

**Problem:** Event cards on `/members/events` stretched to full container width at wide screen sizes.
**Root Cause:** Content area had no `max-w` constraint.
**Fix:** Added `max-w-4xl` to the content container, matching the public events page.

<a name="161"></a>
## 1.6.1 — 2026-04-11

### Defect Fix: Single Event Card Too Wide on Homepage

**Problem:** When only one upcoming event existed, its card stretched the full `max-w-6xl` container width (~1152px), making it look oversized.
**Root Cause:** The single-event render path had no width constraint.
**Fix:** Wrapped the solo event card in `max-w-2xl` when no announcements are present alongside it.

<a name="160"></a>
## 1.6.0 — 2026-04-11

### Feature: Shareable Event Detail Pages

**Value:** Each public event now has its own URL that can be shared via text, email, or social media — with a proper preview card (OG metadata) when pasted into iMessage, Facebook, etc.

#### What's New

- **Event detail page** at `/events/[id]` — full hero banner, image, date/location, description, and back link
- **OG metadata** per event — title, description, and image for social sharing previews
- **Link icon on event cards** — hovering the event title on `/events` reveals a link icon; clicking title or image navigates to the detail page
- **Image aspect ratio standardized** to `aspect-[7/2]` (3.5:1, matching the 1400×400px crop output) across all event display surfaces — fixes images appearing stretched or too short at wide screen widths
- **Google Analytics tag** updated to `G-W30G7GD9HZ`
- **Pre-push skill** updated to require release notes as a mandatory step before every push to main
