## 1.6.0 — 2026-04-11

### Feature: Shareable Event Detail Pages

**Value:** Each public event now has its own URL that can be shared via text, email, or social media — with a proper preview card (OG metadata) when pasted into iMessage, Facebook, etc.

#### What's New

- **Event detail page** at `/events/[id]` — full hero banner, image, date/location, description, and back link
- **OG metadata** per event — title, description, and image for social sharing previews
- **Link icon on event cards** — hovering the event title on `/events` reveals a link icon; clicking title or image navigates to the detail page
- **Image aspect ratio standardized** to `aspect-[7/2]` (3.5:1, matching the 1400×400px crop output) across all event display surfaces — fixes images appearing stretched or too short at wide screen widths
- **Google Analytics tag** updated to `G-W30G7GD9HZ`
- **Pre-push skill** updated to require release notes as a mandatory step before every push to main

#### Files Added
- `src/app/events/[id]/page.tsx` — event detail page with OG metadata
