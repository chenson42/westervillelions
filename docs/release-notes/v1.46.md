## 1.46.0 — 2026-07-28

### Enhancement: Running Income / Expense / Banked-Used Totals While Budgeting

**Value:** The budgeting page already told you *whether* a fund balanced; now it shows
the numbers behind that verdict, updating live as you type — so you can watch a fund
come into balance while you set line amounts in the meeting.

**Changes:**
- Under each fund's balance badge, a compact **Income · Expenses · Banked used** row now
  shows the running budgeted totals, recomputed on every keystroke (and the instant a
  line is soft-deleted or restored).
- The third figure adapts to the fund: when planned expenses exceed income it reads
  **Banked used** (the drawdown from the fund's balance) in amber; a surplus reads **To
  balance**; an exact match reads **Net $0**. This matches the fund-aware balance rule
  the badge already uses — a charitable fund's planned drawdown is shown, not flagged as
  a problem.

**Testing:**
- [x] Typecheck and production build pass; the full unit suite is unchanged (695 tests —
  this is a presentation-only addition over `computeFundLineSums` /
  `computeBudgetBalanceStatus`, which are already covered)
- [ ] Manual: type amounts and watch Income/Expenses/Banked-used update live; confirm a
  charitable drawdown shows "Banked used" without a warning, and an admin surplus shows
  "To balance"; 360px layout
