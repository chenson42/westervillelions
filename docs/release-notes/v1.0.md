## 1.0.0 — 2026-03-25

### Feature: Initial Release

**Value:** Establishes the Westerville Lions Club web presence with a public-facing site, member portal, admin tools, and membership application flow.

#### What's New
- Public website: homepage, about, mission, events, donate, contact
- Member portal with Google OAuth login
- Admin: member management, events, groups, campaigns
- Contact form with Resend email integration
- Membership application feature
- Member export to Zeffy format

#### Key Routes
- `/` — Public homepage
- `/about`, `/mission`, `/events`, `/donate`, `/contact` — Public pages
- `/members`, `/events` (dashboard) — Member portal
- `/admin` — Admin dashboard
