## 1.29.1 — 2026-07-21

### Enhancement: Ledger detail-page navigation + debit card payment method

**Value:** With the dashboard as the Ledger's front door, the per-entity pages needed to fit the new hierarchy — and the books needed a payment method that matches how the club actually pays for things.

**Changes:**
- The Club and Foundation overview pages now have a "Back to Ledger Overview" link, and the redundant Club/Foundation toggle pills are gone from those pages (entity switching lives on the dashboard; Compliance and Reports keep their switchers).
- "Debit Card" is now a payment-method option when recording transactions in either entity's books.

### Defect Fix: Entity overview pages intermittently failed to load

**Problem:** Opening a Club or Foundation overview occasionally showed "This page couldn't load" instead of the page. It was intermittent enough to pass repeated testing and had been provisionally logged as tooling noise.

**Root Cause:** The "Record Transaction" button element was created in a Server Component and passed across the server/client boundary into the dialog's trigger slot — a pattern that intermittently fails inside the dialog library's element-slotting.

**Fix:** The dialog now renders its own trigger button when given a label, keeping element creation inside the client boundary. The same fix was applied to the fund detail pages, and a code comment warns future callers away from the fragile pattern.

**Testing:**
- [x] Previously-failing page passed 4 consecutive verification runs plus the full e2e suite
- [x] Fund-page Record Transaction button verified unchanged visually

## 1.29.0 — 2026-07-21

### Feature: The Ledger Dashboard

**Value:** The Ledger opened onto one entity at a time behind an easy-to-miss toggle — the treasurer literally didn't know the Foundation view existed. The Ledger now opens onto both organizations at once, with the things that need attention surfaced instead of buried.

#### What's New

- **Two-account dashboard.** `/admin/ledger` now lands on side-by-side cards for the Club and the Foundation — true balances, current-year receipts, and alert counts — each card drilling into the familiar per-entity detail view (which is unchanged, including every existing link into it).
- **Uncashed checks, surfaced.** A dashboard panel lists every check that hasn't cleared the bank, across both accounts, oldest first, with its age — anything older than 90 days is visually flagged. (The two outstanding Ohio Lions Foundation checks from March 2026 appear here on day one.)
- **Compliance warnings at the top level.** Guardrail warnings from both entities now appear on the dashboard, each tagged with the organization it belongs to — and the aged-public-fund warning now names the specific fund in its text, so two similar warnings can never be confused again.
- **Audit items.** Out-of-sync dues rows, unreconciled-transaction counts, and (for approvers) the pending-approvals queue depth, all in one panel.

#### Permissions

No new keys — the dashboard sits behind the same Ledger view gates as before; the approvals count remains approver-only.

### Enhancement: Impact page year filters match the books

**Value:** The Giving by Cause year pills showed a fiscal year from before the club's records begin — an always-empty button.

**Changes:**
- Pills now read: **All**, then the three most recent fiscal years — never older than the books' first year of data.
- A **More** pill appears automatically once older data-bearing years exist (so history tucks away rather than vanishing as years roll forward).
- Default view remains the current fiscal year.

### Defect Fix: Admin pages could hide content on phones

**Problem:** At phone widths, several admin pages either forced ugly whole-page sideways scrolling or (after an interim fix) clipped content — buttons and table columns could become unreachable.

**Root Cause:** Wide content (button rows, filter forms, tables) lacked its own scroll or wrap containment, so it fell to the page body to handle overflow.

**Fix:** A sweep of all admin routes at phone width: button rows and filter forms now wrap, tables scroll within their own containers, and the page body never scrolls sideways. Eight surfaces fixed, including Members, Dues, Users, Announcements, Release Notes, and group detail pages.

**Testing:**
- [x] All admin routes verified at 360px (no page-level scroll; all content reachable)
- [x] Desktop layouts verified unchanged at 1280px
