## 1.10.0 — 2026-05-08

### Feature: Suggestion Box

**Value:** Members can now submit ideas for club activities or website/portal improvements directly from the member portal — with the option to remain anonymous. Submissions are emailed to `info@westervillelions.org` and are also captured in an admin-only triage view so nothing slips through the cracks.

#### What's New
- "💡 Suggestion Box" button on the `/members` portal banner opens a dialog with a category dropdown, message textarea, and an "Submit anonymously" checkbox
- Submissions are persisted to a new `suggestions` table and emailed to `info@westervillelions.org` via Resend
- When anonymous, the submitter's name and email are omitted from the email body and reply-to is suppressed
- New `/admin/suggestions` page lists incoming submissions with unhandled/all toggle, mark-handled, anonymous badge, and reply-by-email
- Admin sidebar gets a "Suggestions" nav entry (gated by the new `suggestions.view` feature, granted to `admin` and `board_member` roles) plus a footer launcher to submit a suggestion from inside admin
- Admin dashboard "Needs Attention" panel now surfaces an unhandled-suggestions tile linking to `/admin/suggestions`

#### Files Added
- `drizzle/migrations/0030_suggestions.sql` — `suggestions` table + `suggestions.view` feature seeded for `admin` and `board_member`
- `src/app/api/suggestions/route.ts` — `POST` handler that validates, persists, and emails submissions
- `src/app/api/admin/suggestions/[id]/route.ts` — `PATCH` handler to mark suggestions handled/unhandled
- `src/app/(dashboard)/admin/suggestions/page.tsx` — admin triage list view
- `src/components/suggestion-box-dialog.tsx` — Radix dialog for the submission form
- `src/components/suggestion-box-launcher.tsx` — small button wrapper that opens the dialog
- `src/components/admin/suggestion-mark-read-button.tsx` — optimistic mark-handled button

#### Files Modified
