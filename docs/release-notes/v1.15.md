## 1.15.0 — 2026-05-20

### Feature: Add to Calendar

**Value:** Visitors and members can now save Lions Club events to their personal calendar (Google, Apple, Outlook, or anything that opens `.ics`) with one click. No third-party calendar integrations, no accounts to link — just a download. The button appears on every public event card, every member-portal event card, and on event detail pages.

#### What's New

- **Per-occurrence button** on public and member event list cards downloads a single-event `.ics` for that occurrence.
- **Series-level button** on the detail page of a recurring event downloads the entire recurring series as one `.ics` file (one `VEVENT` per occurrence, all cancelled occurrences filtered out).
- **Single-occurrence button** on the detail page of a non-recurring event.
- All `.ics` downloads emit a `VTIMEZONE` block for `America/New_York` and use `TZID=America/New_York` on every `DTSTART` — calendar apps will display the wall-clock time the admin entered, with correct DST handling in either direction.
- All-day events emit `DTSTART;VALUE=DATE:YYYYMMDD` with no time component.
- Cancelled occurrences are skipped entirely — they do not appear as crossed-out `STATUS:CANCELLED` events in the user's calendar.
- The `.ics` file includes the event title, description, location, a link back to the event page, and a stable UID per occurrence — re-importing updates the existing calendar entry instead of duplicating it.
- Private events (`isPublic = false`) require a signed-in member with `members.view`; public events are anonymous-accessible.

#### Permissions

| Feature key | Required for |
|-------------|--------------|
| (none new) | Public events: anonymous. Private events: reuses existing `members.view`. |

#### New Routes

- `GET /api/events/[id]/ics?occurrence=YYYY-MM-DD` — Single-occurrence `.ics` for the given event and date.
- `GET /api/events/[id]/ics` — Full-series `.ics` for the given event (one `VEVENT` per non-cancelled occurrence).
