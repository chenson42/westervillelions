## 1.8.8 — 2026-04-30

### Feature: Admin User Edit Form; Name/Email Sync Between Users and Members

**Value:** Admins can now edit a user's name and email directly from the portal instead of running database queries. Changes sync automatically to the linked member record and vice versa.

**Changes:**
- Admin → Users list "Manage Roles" link renamed to "Edit"
- User detail page has an editable name and email form above the role manager; validates email uniqueness before saving
- Editing a member's name or email in Admin → Members syncs to the linked user account
- Editing a user's name or email in Admin → Users syncs to the linked member record

<a name="187"></a>
## 1.8.7 — 2026-04-30

### Enhancement: SEO Audit Fixes

**Changes:**
- `og:site_name`, `og:type`, `og:locale` added to all public pages (were dropped due to Next.js shallow metadata merge)
- Public event detail pages included in sitemap dynamically from the database
- `/about`, `/mission`, `/programs` use `revalidate = 3600` for edge caching
- Permissions-Policy expanded with `payment`, `usb`, `accelerometer`, `gyroscope`, `magnetometer`, `display-capture`
- CSP `frame-src` fixed to allow Google Maps embeds (`www.google.com`); Givebutter removed from CSP
- Programs added to the footer

## 1.8.6 — 2026-04-29

### Feature: Configurable Eyeglass Drop-off Locations

Admins can add, edit, activate/deactivate, and reorder drop-off locations from Admin → Programs. 10 Westerville locations seeded on deploy. Public `/programs` page reads from the database.

<a name="185"></a>
## 1.8.5 — 2026-04-29

### Feature: Suspend/Unsuspend User Accounts

Suspend button on the admin Users list with confirmation dialog. Suspended users are blocked at sign-in immediately. Admins cannot suspend themselves. Actions logged to the audit log.

## 1.8.1 — 2026-04-29

### Feature: Event Signups with Per-Occurrence Support

Members can sign up for specific dates of recurring events. Optional capacity cap per occurrence. Members can see who else signed up. Admins can add/remove signups manually. Full details in `docs/features/event-signups.md`.
