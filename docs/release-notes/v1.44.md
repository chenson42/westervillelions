## 1.44.0 — 2026-07-28

First increment of the budgeting-page redesign — a cleaner, printable budget
worksheet you can take into a budget meeting.

### Enhancement: Budgeting Reference Columns + Printable Worksheet

**Value:** Setting a budget is much easier with last year's numbers right next to the
input. This adds prior-year reference and a clean print-out, so the budgeting page
doubles as a worksheet you can hand out and mark up at the board's budget meeting.

**Changes:**
- **Prior-year reference columns.** Each category now shows last fiscal year's **Budget**
  and **Actual** (read-only) next to the editable new-budget field, so you can see what
  you planned and what actually happened while you set this year's number. (The prior
  columns pull from the same figures the fund reports already use — no new data.)
- **Print / Save as PDF.** A print button produces a neat worksheet — one section per
  fund, each category on its own row with its prior-year budget/actual and this year's
  amount, **plus a couple of blank lines under each category** for hand-written
  additions or subtractions during the meeting. The club chrome is hidden in print, and
  a category never splits across a page break. The printout reflects your last-saved
  numbers (not half-typed edits).
- **Simpler, blank-input flow.** The old "seed from last year" preview and its bulk-copy
  buttons were removed — an empty new-budget box is now the signal that you haven't
  addressed a category yet. Prior-year budget/actual sit right there as your reference
  instead. (Entering 0 still means a deliberate $0; leaving blank still removes a line.)
- Approve/lock, "Add category", and the cause/beneficiary breakdown are unchanged.

_This is Increment 1. Soft-delete of budget lines (a removed line stays visible with a
restore toggle until the budget is finalized) is a planned follow-up (Increment 2)._
