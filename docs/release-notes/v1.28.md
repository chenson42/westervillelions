## 1.28.0 — 2026-07-20

### Defect Fix: Fund balances showed stale opening amounts on new fiscal years

**Problem:** With the club's real books imported, opening a fund on the new fiscal year showed its original 2024 opening balance (e.g., Administrative $19,090.10) instead of the true current balance ($16,134.12) — prior years' activity was missing from the displayed figure.

**Root Cause:** Fund summaries computed "opening balance" as the fund's static inception seed rather than rolling it forward through prior fiscal years' posted activity. The Ledger's first year of use masked the flaw; multi-year books exposed it.

**Fix:** Every fiscal-year view now rolls the opening balance forward (seed + all prior-year posted activity) using the Ledger's canonical balance function, consistently across the overview, fund reports, and entity reports. Year-over-year continuity now holds: each year's ending balance equals the next year's opening. (DECISION-029)

**Testing:**
- [x] Current-FY view shows true balances for all four funds (verified against SQL)
- [x] Prior-FY view unchanged where it was already correct; FY-to-FY continuity verified

### Feature: The impact page now tells the true giving story

**Value:** With real books in The Ledger, the member philanthropy dashboard was showing one undifferentiated "Other community support" bucket — and quietly counting fundraiser t-shirts and porta-john rentals as "community giving." Members now see honest, meaningful numbers.

#### What's New

- **Giving by cause.** Every giving transaction now carries a cause — Youth & Education, Hunger & Basic Needs, Vision & Eye Care, Disaster Relief, Health & Disability, Lions International Programs, Community & Civic, Bags to Benches (Recycling) — so the cause breakdown reflects where the money actually went.
- **Fiscal-year filter pills.** The Giving by Cause card now filters by each of the past three fiscal years or All, defaulting to the current year, switching instantly. A year with no giving yet says so and points to All.
- **True gifts only.** Giving totals now exclude fundraising event costs, operations, and insurance — spend in categories marked as overhead no longer counts as community giving. Compliance and 990 surfaces still see full expense totals, as the IRS requires. (DECISION-030)
- **Honest time framing.** The headline reads "Community Giving Since July 2024" (derived from the earliest recorded year) instead of claiming "All-Time."

#### Permissions

No new keys — existing impact-page gating unchanged.

### Enhancement: Grouped admin menu

**Value:** The admin sidebar had grown to two dozen flat items; finding anything meant scanning the whole list.

**Changes:**
- Menu items are now grouped under always-visible section headers: **People**, **Treasury**, **Engagement**, **Inbox**, and **System**, with Dashboard on top.
- Sections a user has no access to disappear entirely.
- Fixed alongside: only the deepest matching menu item highlights (previously "Ledger" stayed highlighted on Compliance/Reports pages).
