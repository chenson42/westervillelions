## 1.102.1 — 2026-11-05

### Bug fix: false "missing receipt" alerts

**Value:** The missing-receipt count now lists only entries that actually need a receipt, so the treasurer isn't chasing ones that are already documented or that can't have a receipt.

#### What's Fixed

- **Paid reimbursements show their receipt.** A reimbursement always arrives with the member's receipt attached, but the ledger entry created when it was paid showed "No receipt" and counted as missing. Because it was approved, it couldn't be waived either. The register now shows "View receipt" for these entries, which opens the receipt from the request, and they no longer count in the compliance check.
- **Transfers no longer count as missing a receipt.** Moving money between the club's own funds produces no receipt, so transfer legs are left out of the check.
- Approved entries stay locked; nothing about editing or waiving them changes.

### Security: Next.js update

- Updated Next.js from 16.3.8 to 16.4.5, which fixes two critical and one high-severity published vulnerabilities in the framework the site runs on.

## 1.102.0 — 2026-11-04

### Feature: copy the storyline, and the storybook

**Value:** The storyline is written once. Howard can rehearse it on the practice session and copy it into the real one in a click, and after the weekend families can save the day's story as a little picture book.

#### What's New

- **Copy scenes from another session.** On a session with no scenes yet, the Scenes card offers "Copy scenes from another session": pick a session (each shows its kind and scene count), confirm, and the titles, text and order are copied. Photos are never copied. It is not offered on a purged session.
- **Clone session brings the storyline.** When the session being cloned has scenes, the clone form shows "Include the N scenes", ticked by default. If the copy cannot be made, no session is created.
- **The storybook.** Once the collage is published and has scenes, it shows "Download the storybook". The storybook is a cover, one page per scene with its title, text and group pictures, and a closing page; "Save as PDF" opens the print dialog, with a short how-to for iPhones. It shows only what the collage shows, never portraits, check-in photos or names, and it is gone when the collage is.
- **Privacy page:** adds "A copy you save stays on your device."

#### Before the event

- Save the storybook as a PDF from Chrome on a computer and check that no web address prints in the page margins, and try Save to Files from an iPhone.
- The other phone checks in B-212 still apply.
