## 1.27.0 — 2026-07-20

### Feature: Dues Payment-Method Donut Chart

**Value:** The dues page's paid/partial/unpaid stat cards told the treasurer *who* had paid but nothing about *how* the money arrived. The new donut shows the year's dues composition at a glance — and keeps the total collected front and center.

#### What's New

- The admin dues page now opens with a donut chart composing the fiscal year's expected dues in dollars: collected by **Check**, **Zeffy**, **Cash**, and **Other**, plus a muted **Unpaid** slice for what's still outstanding.
- **Total collected** sits in the donut's center, with the precise dollar figure alongside.
- Paid / partial / unpaid member counts remain in compact form beneath the chart.
- Legend shows per-method dollar amounts; a screen-reader table mirrors the chart so color never carries meaning alone.

No new permissions or routes — the chart lives on the existing dues page under the existing gates.

### Defect Fix: Sidebar highlighted two menu items on Ledger subpages

**Problem:** Opening Compliance or Reports from the admin menu left "Ledger" highlighted alongside the page you were actually on.

**Root Cause:** A nav item was marked active whenever the current path started with its href — and `/admin/ledger` is a prefix of every Ledger subpage.

**Fix:** Only the deepest matching menu item highlights. Ledger pages without their own menu entry (approvals, fund details) still highlight "Ledger."

### Defect Fix: Dues list forgot its filters after viewing a member

**Problem:** Filtering the dues list (status tab or search), opening a member's detail, and clicking "Back to Dues List" returned an unfiltered list.

**Root Cause:** The row links carried only the fiscal year into the detail page, so the back link couldn't restore what it never received.

**Fix:** Status and search now ride along to the detail page and back; the fiscal-year selectors preserve them too.

**Testing:**
- [x] Sidebar: Compliance page highlights only "Compliance"; approvals page still highlights "Ledger" (verified signed-in)
- [x] Dues: `?status=unpaid` → View → Back returns to the filtered list (verified signed-in)

### Infrastructure: Treasurer's Books Onboarding

**Background:** The club's real books (Quicken registers for both bank accounts, July 2024–June 2026) were imported into The Ledger, reconciling exactly to both accounts' register balances. The review that accompanied the import produced a standing checklist.

**Changes:**
- New idempotent import script seeds The Ledger from the treasurer's Quicken register exports (dry-run by default; source files stay outside the repo).
- New `docs/treasurer-todo.md` — the treasurer's living checklist of book-keeping, compliance, and data-cleanup follow-ups, referenced from CLAUDE.md so it's maintained during all Ledger work.
- Both entities' real EINs and the Foundation's public-charity status are now recorded in the Ledger's entity records (previously placeholders).
