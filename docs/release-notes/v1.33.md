## 1.33.0 — 2026-07-21

### Feature: HEIC Receipt Photos in Every Browser

**Value:** v1.32 made iPhone HEIC receipt photos upload in Safari, but Chrome
and Firefox users hit a dead end ("use Safari, or export the photo as JPEG").
The treasurer records expenses from desktop Chrome, so AirDropped receipt
photos now have to just work there too.

#### What's New

- Picking a HEIC photo in Chrome or Firefox now converts it right in the
  browser and uploads it like any other photo — no Safari detour, no manual
  JPEG export. The converter downloads on demand the first time it's needed;
  normal uploads (and Safari) never fetch it.
- If the conversion still can't happen, the error now says why: one message
  when the converter couldn't be downloaded (check your connection and retry),
  a different one when the photo itself won't convert (corrupt or mis-named
  file). Neither tells you to "use Safari" anymore — which was previously
  shown even when Safari itself was the browser that failed.
- The status hint under the file input is now honest about what's happening:
  "Preparing photo…" while converting, then "Uploading receipt…" during the
  actual upload.

#### Permissions

No changes — attaching receipts still requires `ledger.record`, and the
upload endpoint is unchanged (it still only ever receives JPEG/PNG/PDF).

---

### Enhancement: Actionable Compliance Notice on the Ledger Overview

**Value:** The "expenses missing receipt documentation" audit item gained a
"View flagged transactions" link in v1.31 — but only on the entity detail and
compliance pages. The Ledger overview showed the same notice with no way to
act on it.

**Changes:**
- The receipt-documentation audit item on the Ledger overview now carries the
  same "View flagged transactions →" link, jumping straight to the register
  filtered to exactly the expenses still missing receipts.
